# Lime Health dizayn tizimi

Tizimning to'liq matni boshqa AI vositalari bilan umumiy bo'lishi uchun `docs/design-system/` ichida turadi.

1. UI ishini boshlashdan oldin **`docs/design-system/README.md`** ni to'liq o'qing — tokenlar, antd qoidalari,
   retseptlar, taqiqlar, o'tkazish tartibi va tekshiruv shu yerda.
2. Komponent bo'yicha batafsil qoida kerak bo'lsa: `docs/design-system/reference/components.md`;
   brend kitobi: `docs/design-system/reference/brand-book.md`; asl tokenlar: `docs/design-system/reference/tokens.json`.
3. Sahifani o'tkazib bo'lgach, README'ning "Holat" bo'limini yangilang.
